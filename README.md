# Cookie Clicker

Бот для автоматической игры в Cookie Clicker с использованием YOLO-детекции и `mss` для быстрых скриншотов.

## Возможности

Автоматический клик по печеньке 
Автоматическое закрытие рекламы 
Глобальная аварийная остановка по клавише **Пробел**
Защита от кликов за границами экрана и после остановки
